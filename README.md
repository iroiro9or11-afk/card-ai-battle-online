# カードAI対戦ゲーム Online v3.27.9

## V3.27.9 ストーリー抽選・対戦相手・編成表示の修正

- 5戦予定に表示された相手と、抽選後・対戦直前・実戦で使われる相手の同一性を保証するため、相手のスナップショットを一本化しました。
- 旧ドラフトに残った「即席ライバル」と作成済みライバルの内部ID/種別の混在を修復します。
- 保存された相手デッキの参照が有効なら、読み込み時に現在のライバルデッキで勝手に置き換えないようにしました。
- 抽選モーダルを閉じた後、ストーリー用デッキ編成と次の対戦相手デッキを再描画し、編成エリアへスクロールします。

## 実行

```bash
npm install
npm start
```

## テスト

```bash
npm run test:all
```

ストーリーの予定相手、抽選後表示、デッキ編成、次の相手のデッキ、対戦開始時の実デッキを横断するV3.27.9専用回帰テストを追加しています。
