# カードAIバトル オンライン対戦版

オンライン対戦の準備フローを整理した版です。

## オンライン対戦の流れ
1. 部屋を作る / 部屋に入る
2. 部屋内でオンライン対戦に使うデッキを選ぶ
3. 両者が準備完了
4. 無制限・レンタルはそのデッキで対戦開始
5. 超レンタル・闇鍋は選択デッキをカードプールとしてサーバー抽選
6. 抽選候補からキャラクター3～5枚、マジック0～10枚を選択
7. 両者の選択確定後に対戦開始

「対戦準備」のデッキ・出撃設定とはオンライン対戦のデッキ選択を分離しています。

## 起動

```bash
npm install
npm start
```
