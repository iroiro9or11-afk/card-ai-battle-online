# カードAIバトル Online v3.28.9

V3.28.9では、条件未達のマジックカードやスキルが発動・適用される問題、追加効果の対象条件が無視される問題、HP変動時パッシブの発動漏れ、およびオンライン行動確定が止まりうるケースを修正しました。

主な変更点:
- マジックカード・スキルの発動条件をサーバーの実行時にも再検証し、条件未達はAPを消費せず不発扱いにします。
- 追加効果「メイン効果と同じ対象」でも、追加効果自身の属性/HP条件を対象ごとに判定します。未知の対象条件は適用対象外として扱います。
- HP減少/増加時のパッシブをHP変化直後に処理し、HP減少で戦闘不能になった場合もHP減少トリガーを取りこぼさないよう修正しました。最大HP減少やバフ/デバフ解除によるHP減少でも、必要なパッシブ・死亡処理を実行します。
- 使用禁止中、発動条件未達、または有効対象なしのスキルでターン全体が拒否されないようにし、対象がなければ行動のみ不発（AP消費なし）にします。
- オンラインの行動エラー後にサーバー状態を再取得し、入力ボタンが古いフェーズ情報でロックされ続けるのを防ぎます。

テスト: `npm run test:all`

詳細は `PATCH_NOTES_V3.28.9.md` を参照してください。
