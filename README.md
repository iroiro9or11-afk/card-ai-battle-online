# カードAI対戦ゲーム Online v3.23.0

## v3.13から継承した修正（HP・相手カード・タイマー）

### 主な修正
- 行動演出ポップアップの対象HPが `NaN` にならないよう、サーバーとクライアントのHPスナップショットを数値正規化。
- レンタルを含むオンライン対戦で、相手キャラクターの画像をサーバー側の公開戦闘状態から確実に取得。
- 対戦中に相手のキャラクターカードだけでなく、選択したマジックカードも公開表示。使用済みマジックはグレー表示。
- オンライン中に公開された相手カードをキャッシュし、相手キャラクター／マジックの詳細表示を可能化。
- 相手キャラクターのスキル情報もオンライン詳細表示用に公開。
- 90秒コマンド入力タイマーはサーバーの `deadline` を基準に動作し、行動演出中も表示を消さず「処理中」を表示。次ターンの決定フェーズに入った時点で即座に新しい90秒カウントを開始。
- ポップアップ演出の待ち時間によって90秒タイマーの開始が遅れる問題を修正。

### 仕様
- 90秒はコマンド入力フェーズの制限時間。行動実行フェーズでは時間を消費せず「処理中」と表示。
- 相手の選択済みマジックカードは戦闘画面で公開される。使用済みカードも一覧から消さず、使用済み表示のみ行う。

## v3.16 修正
- オンライン戦闘状態・イベントからカード画像の大容量データを分離し、カード情報と画像アセットを別送信
- 対戦前のdeployment_optionsも画像アセットを別同期し、相手側カード画像の後追い同期に対応
- battle_event / turn_start の通信を軽量化し、ポップアップ・次ターン開始が画像サイズに左右されないよう修正
- 相手キャラ・マジックの画像を共通キャッシュから解決し、詳細表示・戦闘演出で同じ公開情報を利用
- バトルイベントに画像を重複送信しない


今回の修正: デッキ選択画面で先頭のデッキが自動選択されている場合でも、サーバーへ deck_select を自動送信し、deployment_options を取得してキャラクターカード・出撃設定を表示するようにしました。レンタルでも同様に、公開デッキ一覧を受信したら先頭デッキを自動選択・要求します。


## v3.18.0
- ページ更新・WebSocket再接続後にオンライン画面を自動復元し、オフライン対戦準備画面へ戻らないよう修正

- デッキ選択リクエストの初期化・再送制御を整理

- 戦闘イベント表示中は最新戦闘状態を保留し、ポップアップ終了後にまとめて反映することでコマンド画面が途中で消える問題を抑制
- 戦闘状態描画の例外保護を追加し、ターン開始処理がUI例外で停止しないよう修正
- オンライン版のバージョン表記を3.18.0へ統一


## v3.19.0 オフライン戦闘修正
- 行動開始ボタンを常に押せる状態にし、AP不足や対象未選択はクリック時に明示して予約内容を修正できるように変更。
- AP予約合計を予約変更のたびに再計算し、「AP予約合計 / 現在AP」を戦闘画面に表示。
- 指定対象スキル・マジックの対象選択時もAP予約表示を即時更新。
- 相手のマジックカードをオフラインでも戦闘開始時から全て公開。
- 相手マジック表示を「プレイヤー名・ターン表示UIの直下、敵キャラカードの上」へ移動。

## v3.20.0 オフライン戦闘修正
- 敵側の「自分/相手プレイヤー」対象を正しく解決し、AP増加・減少効果が対象なしで不発になる問題を修正。
- マジックカード発動ポップアップを修正し、カード名・説明文・効果・結果を表示。
- 2ターン目以降の行動コマンドパネルを毎ターン再表示。
- 戦闘終了時に勝利・敗北・引き分けの結果ポップアップを表示し、「再戦」「戻る」を追加。


## v3.21.0 戦術AI強化
- AI難易度に「達人」を追加。
- 「玄人」を強化し、キャラクター個別ではなくターン全体の共有APを考えて行動を組み立てるよう変更。
- 玄人／達人はスキル対象の撃破確定、回復優先、行動値、バフ・デバフ、状態異常、スキル禁止、AP増減などを総合評価。
- 達人はビームサーチで複数キャラクター＋マジックの組み合わせを探索し、次ターンのAP、将来価値、敵からの反撃リスクまで含めて候補を比較。
- 同ターンの共有APを超える予約を避け、APを使い切るだけでなく「残す価値」も評価。
- 達人は同じ盤面でも完全固定にはせず、僅かなタイブレーク乱数で自然な行動揺らぎを残す。


## V3.22.0 ストーリートーナメント
- カード一覧から開始時にキャラ5枚＋マジック10枚をランダム解放。
- 32人固定のシングルエリミネーション（5勝で優勝）。
- 勝利ごとに未解放カードからキャラ3枚＋マジック5枚を追加解放。
- 登録ライバルを優先利用し、不足枠はカード一覧から生成した即席ライバル（素人～凡人）で補充。
- プレイヤー以外の試合は高速AIシミュレーションで裏処理。
- 試合間にストーリー専用デッキを再編成可能。
- ストーリー進行はIndexedDBへ保存し、ページ更新後も再開可能。
- 敗北／引き分けはトーナメント終了。新しいトーナメントを再抽選して再挑戦可能。


## v3.23.0 変更点

### 全体
- カード詳細モーダルを拡大し、カード画像・説明・スキル説明を読みやすくしました。
- 戦闘中のプレイヤー／相手マジック表示を縦2×横5のグリッドへ変更しました。
- 使用済みマジックカードもクリック／長押しで詳細確認できるようにしました。

### ストーリーモード
- ストーリー用デッキ編成に「初期出撃3体」と「控え最大2体」の独立した設定を追加しました。
- 戦闘開始時は設定した初期出撃3体を使用し、控えは設定順に登場します。
- デッキ選択欄の上に確定した出撃／控え編成を表示します。
- 開始前にも32人トーナメント表を表示し、ライバル枠を自由に変更できます。
- トーナメントのランダム再生成機能を追加しました。
- 戦闘開始前に回戦、プレイヤー、ライバル、アイコン、AI難易度を表示する対戦開始ポップアップを追加しました。
- プレイヤー勝利後は自動で次戦へ進まず、勝利報酬カードを結果ポップアップで表示し、「編成画面へ戻る」でストーリー編成画面へ戻る仕様に変更しました。
- 開始後も進行中のトーナメント表を表示し、現在の回戦を強調します。

### テスト
