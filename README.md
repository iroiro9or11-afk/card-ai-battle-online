# カードAIバトル Online v3.28.7

V3.28.7ではオンライン・オフライン両方の戦闘アクションポップアップの最低表示時間を5秒へ変更しました。オフライン戦闘ではポップアップ本体の外側（暗い背景）をタップすると、現在のポップアップ待機を解除して次のポップアップへ進めます。オンライン戦闘では両クライアント間のイベント表示順序を守るため、背景タップによる早送りは無効です。

## 起動

```bash
npm start
```

本番のオンライン入力時間は90秒です。回帰テストでは `CARD_BATTLE_DECISION_MS` 環境変数を短くして時間切れを再現します。

`client/index.html` が配信されるクライアントの正本です。`all_scripts_v327.js` はHTML内のインラインスクリプトから生成した補助ファイルです。

詳細は `PATCH_NOTES_V3.28.7.md` を参照してください。
