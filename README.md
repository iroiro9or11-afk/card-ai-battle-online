# カードAIバトル Online v3.28.8

V3.28.8ではオンライン対戦のモード選択に「カード交換」を追加しました。両プレイヤーが所持カードから0～5枚を選び、相手が選んだカードのデータと画像を受け取り、ローカルのIndexedDBへ新しいカードとして保存します。交換に出した元カードは削除されず、コピー共有として扱います。交換完了後は「続ける」か「やめる」を選択でき、続ける場合は両者の同意後に次の交換へ進みます。

- 交換対象：キャラクターカード・マジックカード
- 最大選択枚数：1人につき5枚（0枚も可）
- カード情報：ステータス、ランク、スキル／効果、説明などを保持
- 画像：カード本体とは別のアセット通信で転送し、受信側のローカル保存時に再結合
- 所持カード：送信側から削除せず、受信側ではIDを新規発行して既存カードの上書きを防止
- 再交換：両者が「続ける」を選択した場合のみ新しい交換ラウンドへ進行

詳細は `PATCH_NOTES_V3.28.8.md` を参照してください。
