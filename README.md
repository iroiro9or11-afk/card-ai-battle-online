# カードAIバトル Online v3.28.2

V3.28.2では、カード一覧・デッキ編集の5列表示、キャラクターカードのランク／属性フィルターとステータス順ソート、マジックカードのAP・行動値・効果種別ソートとフィルター、ストーリー控えカードのサイズ統一、ライバルアイコンのトリミング・保存・編集反映を修正しました。
