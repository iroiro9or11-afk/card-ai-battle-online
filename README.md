# カードAIバトル Online v3.28.3

V3.28.3では、ライバルアイコンの保存後反映、敵の予約行動の秘匿、HP減少時パッシブの即時発動、ストーリー戦闘の控え／敗北終了、複数対象ポップアップを修正しました。

詳細は `PATCH_NOTES_V3.28.3.md` を参照してください。

## 起動

```bash
npm start
```

`client/index.html` が配信クライアントの正本です。`all_scripts_v327.js` はHTML内のインラインスクリプトから生成した補助ファイルです。

## テスト

```bash
npm run test:all
```
