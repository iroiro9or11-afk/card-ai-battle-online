# カードAIバトル Online v3.29.4

V3.29.0では、対象指定と味方コマンド選択の競合、オンラインタイマー位置、HP 0のキャラへのHP操作、闇鍋候補カードの重複、カード交換完了ポップアップを修正しました。

## 主な変更点
- 指定対象が確定済みなら、別の味方カードのタップをそのキャラのコマンド選択に使えるように修正。
- 常に右上に表示される大きいカウントタイマー本体だけをドラッグ移動可能に変更。小さい戦闘画面内タイマーと操作パネルは移動対象外。
- HP 0になったキャラのHP減少時パッシブを停止し、回復・最大HP操作も拒否して、致死ダメージからの無限復活を防止。
- 闇鍋では交換で共有されたカードも元カードIDで重複排除してから候補抽選。
- カード交換完了時、受け取ったカードを画像付きで即時表示。

## 起動
```bash
npm install
npm start
```

## テスト
```bash
npm run test:all
```
