# カードAIバトル Online v3.28.0

## V3.28.0 オンラインカード画像同期の横断修正

- 戦闘stateに含まれる`image:null`が、別送された画像キャッシュを消してしまう問題を修正。
- 超レンタル／闇鍋の候補カード本体と画像アセットを別通信に分割し、大きな候補一覧での送信失敗を防止。
- 超レンタル候補のランクをカード描画へ明示的に引き渡すよう修正。
- 候補プールは両者の画像同期が完了してから生成し、同期前の古いプロフィールを参照する競合を修正。
- Data URLだけでなく、IndexedDBにBlob/Fileとして保存されている画像もオンライン同期時にData URLへ変換。
- 借りたカードIDがローカルにも存在する場合に、戦闘フィールドはサーバーで確定したカード画像を優先。通常のローカルカード表示ではIndexedDBのBlob画像を優先。
- 共通画像取得関数は空の`image`フィールドで有効な`img`／`imageUrl`を隠さないよう修正。
- 無制限・レンタル・超レンタル・闇鍋・観戦・再接続の各アセット経路をテスト。

`npm run test:all`ですべての回帰テストを実行できます。
詳細は`PATCH_NOTES_V3.28.0.md`を参照してください。
