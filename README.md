# カードAI対戦ゲーム Online v3.8

## v3.8 オンライン対戦再構築

オンライン対戦部分を、部屋管理・WebSocket接続・ルール別カード配布・サーバー権威型バトル・観戦・再接続まで一貫した状態管理になるよう再構成しました。

### 主な修正
- 部屋作成ボタンを押しても無反応になる状態を避けるため、WebSocket接続状態を画面へ表示し、接続待ちの要求を安全にキュー化。
- `hello` 認証とプロフィール同期を部屋操作から分離。ページ読み込み直後でも部屋作成・入室要求が順序どおり処理される。
- WebSocket切断時に観戦者とプレイヤーを区別。観戦者の切断で対戦を一時停止しない。
- プレイヤー切断時は決定フェーズの残り時間を保持して停止。再接続時は同じターン・同じAP・同じ確定済み行動を維持して再開する。
- レンタルは部屋作成者のデッキ一覧だけを共有し、選択したデッキの実カード情報を使用プレイヤーへ同期。
- 超レンタルは部屋作成者のカードリスト全体から、各プレイヤーへ独立してキャラ10枚＋マジック20枚を抽選。プレイヤー間の重複は許可、各人の候補内重複はなし。
- 闇鍋は両プレイヤーのカードリストを合成した母集団から、各プレイヤーへ独立してキャラ10枚＋マジック20枚を抽選。
- 無制限・レンタルでも、デッキ選択後に初期出撃3体と控え順を確定してから準備完了する方式へ整理。
- サーバー側でデッキ枚数・候補カード・出撃順・対象・スキル条件・累積AP・マジック使用済み状態を検証。
- 通常攻撃の攻撃力に100未満の下限を設けない。
- マジックカードはサーバーから使用者本人へカード情報を同期するため、レンタル・超レンタル・闇鍋でも表示可能。
- 選択対象を必要とするオンラインマジックにも対象IDを送信し、サーバーで検証。
- ターンタイマーはサーバー基準の90秒。時間切れ時はサーバー側のおまかせ行動を生成。
- 同一ターン中も各行動のたびに現在の行動値を再計算し、バフ・デバフ後の値を次の行動順へ反映。
- 連続して届く戦闘イベントのポップアップをクライアント側でキュー処理し、演出の競合で次ターンのコマンド画面が壊れないように修正。
- サーバーのWebSocketフレーム処理を整理し、メッセージサイズ上限・ping/pong・close処理を追加。

## 起動

```bash
npm install
npm start
```

オンライン対戦は `server.js` が配信するWebページから利用してください。`client/index.html` を `file://` で直接開いた場合、同一ホストのWebSocket接続先を作れないためオンライン対戦は利用できません。

## オンライン疎通テスト

```bash
npm run test:online
```

テストでは、部屋作成・入室・出撃設定・準備・戦闘開始・ターン実行・観戦者切断・プレイヤー切断・再接続・超レンタル・レンタル・闇鍋を確認します。
