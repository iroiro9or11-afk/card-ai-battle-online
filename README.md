# カードAIバトル Online v3.28.5

V3.28.5は、敵AIのマジックカードについて対象指定と発動条件の評価を修正し、ストーリーモード第5戦勝利時のカード報酬を廃止した修正版です。

- 敵AIのマジック発動条件をプランナー／軽量AI／実際の発動時で評価
- 敵AIのマジック対象IDをプレイヤー側の選択対象IDから分離
- マジックの指定対象候補で対象条件・隠密・挑発を考慮
- ストーリー5戦目勝利時は追加カード・報酬履歴を付与せず、クリアとして完了

配信されるクライアントの正本は `client/index.html` です。`all_scripts_v327.js` はHTML内のインラインスクリプトから生成した補助ファイルです。

検証：`npm run test:all` 全テストPASS。
詳細は `PATCH_NOTES_V3.28.5.md` を参照してください。
