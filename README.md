# カードAI対戦ゲーム Online v3.27.2

## v3.27.2 スキル追加効果・オンライン戦闘整合性修正
- オフライン／オンライン／パッシブで「メイン効果の成功後だけ追加効果」を統一。
- 「メイン効果と同じ対象」は、実際に解決されたメイン対象をそのまま追加効果へ渡すよう修正。
- メイン効果と追加効果で対象指定が別の場合、追加効果用の対象を独立して選択・送信・検証。
- オンラインのマジック追加効果対象をクライアントからサーバーへ送信。
- オンラインのタイムアウト自動行動が、追加効果の指定対象も解決してから送信するよう修正。
- 通常攻撃の対象はオンラインでも常に現在フィールドからサーバー側でランダム決定。
- オンライン戦闘UIで追加効果だけが指定対象の場合も対象選択欄を表示。
- カード編集ボタンを毎回安全に上書きし、詳細表示を開き直した際のイベント蓄積を防止。
- 実際に配信される client/index.html を正本として all_scripts_v327.js も同期。
- サーバー・クライアント・パッケージのバージョンを v3.27.2 に統一。
- WebSocket実戦型のV3.27.2回帰テストを追加し、同一対象・別対象の追加効果、メイン効果失敗時の追加効果抑止、マジック追加対象を検証。

## v3.27.1 スキル追加効果対象修正
- 追加効果に「メイン効果と同じ対象」を追加。
- 追加効果は独立した対象タイプ・対象条件を持ち、指定対象なら戦闘コマンドで別対象を選択可能。
- メイン効果が成功しなかった場合、追加効果は発動しない。
- バフ・デバフは重複可能。状態異常は同一種類の重複不可。旧 `stackable` 設定は実行時に参照しない。
- 攻撃力参照ダメージの説明を「攻撃力×○％のダメージ」に統一。


## v3.13から継承した修正（HP・相手カード・タイマー）

### 主な修正
- 行動演出ポップアップの対象HPが `NaN` にならないよう、サーバーとクライアントのHPスナップショットを数値正規化。
- レンタルを含むオンライン対戦で、相手キャラクターの画像をサーバー側の公開戦闘状態から確実に取得。
- 対戦中に相手のキャラクターカードだけでなく、選択したマジックカードも公開表示。使用済みマジックはグレー表示。
- オンライン中に公開された相手カードをキャッシュし、相手キャラクター／マジックの詳細表示を可能化。
- 相手キャラクターのスキル情報もオンライン詳細表示用に公開。
- 90秒コマンド入力タイマーはサーバーの `deadline` を基準に動作し、行動演出中も表示を消さず「処理中」を表示。次ターンの決定フェーズに入った時点で即座に新しい90秒カウントを開始。
- ポップアップ演出の待ち時間によって90秒タイマーの開始が遅れる問題を修正。

### 仕様
- 90秒はコマンド入力フェーズの制限時間。行動実行フェーズでは時間を消費せず「処理中」と表示。
- 相手の選択済みマジックカードは戦闘画面で公開される。使用済みカードも一覧から消さず、使用済み表示のみ行う。

## v3.21.0 戦術AI強化
- AI難易度に「達人」を追加。
- 「玄人」を強化し、キャラクター個別ではなくターン全体の共有APを考えて行動を組み立てるよう変更。
- 玄人／達人はスキル対象の撃破確定、回復優先、行動値、バフ・デバフ、状態異常、スキル禁止、AP増減などを総合評価。
- 達人はビームサーチで複数キャラクター＋マジックの組み合わせを探索し、次ターンのAP、将来価値、敵からの反撃リスクまで含めて候補を比較。
- 同ターンの共有APを超える予約を避け、APを使い切るだけでなく「残す価値」も評価。
- 達人は同じ盤面でも完全固定にはせず、僅かなタイブレーク乱数で自然な行動揺らぎを残す。


## V3.22～V3.24 ストーリーモード旧版
- 以前は32人トーナメント方式で実装していました。
- 現在のV3.26.0では、この方式を廃止し、5戦の順番制ストーリーモードへ変更しています。


## V3.26.0 変更点
- ストーリーを32人トーナメントから「全5戦」に変更。
- 登録ライバルから5人をランダム選出し、不足分は素人～凡人の即席ライバルを自動生成。
- 対戦順は強さを考慮して並べ、後半ほど賢い相手になりやすい構成。
- 開始前にも5人の対戦予定を確認・変更可能。
- ストーリー開始前に、最初に受け取るキャラ5枚＋マジック10枚を確認し、そのままストーリー用デッキを編成可能。
- 初期出撃3体＋控え最大2体を開始前／開始後の両方で設定可能。
- ストーリー編成画面では次の対戦相手のキャラ／マジックデッキを確認可能。
- 勝利ごとに未解放カードからキャラ3枚＋マジック5枚を追加解放。
- 勝利後は自動的に次戦へ進まず、結果ポップアップを閉じて編成画面へ戻り、次戦のデッキを組み直せる。
- 戦闘開始前に第何戦か、プレイヤー名／アイコン、ライバル名／アイコン、AI難易度を表示。
- 戦闘終了結果ポップアップを大型化し、勝利報酬カードを大きく表示。
- 旧32人トーナメント状態は5戦モードへ自動移行。
- IndexedDBにストーリー進行を保存し、ページ更新後も再開可能。

### テスト
