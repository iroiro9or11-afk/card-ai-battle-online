# カードAIバトル Online v3.28.6

V3.28.6は、オンライン対戦で時間切れ後に行動開始ボタンが無効のまま残る問題への対策版です。新しいターン開始通知ごとに入力ロックをリセットし、演出キューが空なのにターン準備確認が停滞した場合は、安全にサーバー状態を再同期して準備完了を再通知します。実行中・演出中のポップアップを飛ばして準備完了にすることはありません。

## 起動

```bash
npm start
```

本番の入力時間は90秒です。回帰テストでは `CARD_BATTLE_DECISION_MS` 環境変数を短くして時間切れを再現します。

`client/index.html` が配信されるクライアントの正本です。`all_scripts_v327.js` はHTML内のインラインスクリプトから生成した補助ファイルです。

詳細は `PATCH_NOTES_V3.28.6.md` を参照してください。
