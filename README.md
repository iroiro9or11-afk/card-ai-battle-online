# カードAI対戦ゲーム Online v3.5

## v3.5 修正
- 戦闘中にポップアップ表示処理の一部が失敗しても、戦闘全体がrejectして実行フェーズで停止しないように修正。
- 行動演出・ターン終了・次ターン開始の各所にエラー復旧を追加し、コマンド選択画面が消えたままにならないよう修正。
- 行動決定ボタンの二重押しによる同一ターンの二重実行を防止。
- ポップアップは先に最小表示を開き、詳細UIの一部エラーでも演出を継続できるよう修正。
- カード長押し詳細をV18系の操作方式に戻し、通常タップを横取りしないよう修正。
- スマホはtouchstart/touchendで長押しを判定し、戦闘中の通常タップは従来どおり行動選択へ渡す。
- PC/ペンはpointerイベントで長押しを判定。
- 長押し成立後の合成clickとカード上のブラウザcontextmenuだけを抑止。
