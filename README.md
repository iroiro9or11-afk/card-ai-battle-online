# カードAI対戦ゲーム Online v3.27.5

## v3.27.5 ストーリーモードの保存データ復旧パッチ
- カードIDを旧形式からUUIDへ移行する際、ストーリーモードの保存状態／編成案のカードID参照も同時に移行。
- 以前の起動ですでに旧ID参照が取り残されたデータも検出して修復。
- プレイヤーデッキだけでなく、5戦すべての相手デッキを検証し、無効なカードIDを有効なカードへ置換。
- 完了済みストーリーで「次の相手なし」が正常に保たれるよう修正。
- 追加のストーリーモード回帰テストを追加。
